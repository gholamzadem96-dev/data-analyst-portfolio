**Tools:** SQL, SQLite, DB Browser for SQLite

**Key Findings:**
- Total Revenue: $149,501.95
- Gross Profit: $67,832.95
- Gross Profit Margin: 45.37%
- Identified top-performing products and customer segments using Pareto and ABC analysis.
