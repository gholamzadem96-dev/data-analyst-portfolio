# SQL Analysis Queries

This folder contains SQL queries developed for the Online Store Business Analysis project.

## Query Categories
- Business Performance Overview
- Regional Sales Performance
- Category Performance
- Monthly and Quarterly Sales Trends
- Product Profitability Analysis
- Customer Value and Segmentation
- Repeat Customer Analysis
- Discount Performance
- Product Pareto and ABC Analysis

## Main SQL Techniques
- SELECT, WHERE, GROUP BY, ORDER BY
- Aggregate functions: SUM, COUNT, AVG
- Common Table Expressions (CTEs)
- CASE WHEN statements
- Window functions: RANK and cumulative SUM
- Date functions and data transformation
- ROUND, CAST, and string functions

## Main SQL File
[`sales_analysis.sql`](./sales_analysis.sql)

The queries are written for SQLite and use a table named `sales`.
